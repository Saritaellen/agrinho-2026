## 📌 Tema
Projeto voltado para ajudar produtores rurais com informações climáticas e decisões de plantio.

## 🎯 Objetivo
Usar tecnologia para reduzir perdas na agricultura causadas por clima instável.

## 💡 Funcionalidades
- Simulação de previsão do tempo
- Dicas de plantio (soja e milho)
- Calculadora de produção por hectare
- Alertas automáticos

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript

## 📱 Responsividade
O site funciona em celular, tablet e computador.

## 🚀 Como usar
Abra o arquivo `index.html` no navegador.
